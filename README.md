# Seguimiento gerencial DTE

Prototipo interactivo para el seguimiento de las actividades estratégicas de la Dirección Técnica y de Estructuración (DTE).

## Uso

Abra `Seguimiento_Gerencial_DTE_Prototipo_2.html` en un navegador. El tablero permite consultar las actividades, usar el modo presentación y exportarlo a PowerPoint o PDF.

La aplicación utiliza bibliotecas cargadas desde CDN, por lo que requiere conexión a Internet para las funciones de importación y exportación.
